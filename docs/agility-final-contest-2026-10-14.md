# 敏捷表加值与 D20：最终规则及验证

日期：2026-10-14。按用户最后明确的规则执行，替代前两轮规则和中途的有效敏捷相加解释。

## 最终算法

1. 从人物卡及数值引擎读取当前有效敏捷，保留基础、装备、饰品、状态来源；现有有效敏捷最低 1 的规则保持。
2. 按下表换算敏捷属性加值。
3. 双方分别由服务器独立掷 1D20。
4. **最终判定值 = MAX(1, 敏捷属性加值 + D20 点数)**。最低 1 在骰子与加值相加之后处理，不提前把负加值改为 1；敏捷数值用于查表。
5. 攻击方严格大于关联目标才命中，相等仍闪避，自然 1/20 无特殊效果。

| 当前有效敏捷 | 属性加值 |
| --- | --- |
| 0–2 | −4 |
| 3–4 | −3 |
| 5–6 | −2 |
| 7–9 | −1 |
| 10–12 | 0 |
| 13–15 | +1 |
| 16–18 | +2 |
| 19–20 | +3 |
| 21–22 | +4 |
| 23–24 | +5 |
| 25–26 | +6 |
| 27–28 | +7 |
| 29–30 | +8 |
| 31–32 | +9 |
| 更高敏捷 | 4 + floor((敏捷 − 21) / 2)，每 2 点增加 1，无额外上限 |

冒险家：基础 2 + 戒指 2 → 敏捷 4 → 加值 −3；掷 5 → 最终 2，掷 1 → 原结果 −2 → 按 1，掷 3 → 原结果 0 → 按 1。铁傀儡按同一规则计算，与冒险家的最终值比较。
