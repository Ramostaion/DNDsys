# 人物卡、地图人物与生命归零拾取 · 2026-10-11

## 实际修改

1. 自定义人物卡将配置的生命与上限提到“基础信息”之前；不改变字段 ID、分组定义、原始值或编辑权限。
2. 地图人物右键改为“不显示当前人物 / 复制当前人物”，仍仅 GM 可执行。
   - 不显示：移除点击的地图图标，人物卡和背包保留，可从目录重新拖入。
   - 复制：创建独立人物卡及旁边的地图图标，复制头像、数值、能力/状态、NPC 搜索许可、背包实例、穿戴关系和标签独立备注。物品/模板/标签定义继续引用现有库，交易与战斗历史不复制。旧接口保留兼容。
3. 黄色最终数值旁的 i 使用悬停/键盘聚焦显示来源：白色基础、绿色加成、红色减少；旧人物卡自定义数值同样支持。加、乘、覆盖按实际运算顺序记录增减量，不把乘数误当加成值。已有公式与字符串来源保留；无背包查看权限时不返回装备详细来源。
4. 玩家人物有效生命 ≤ 0 时：
   - 本人背包/装备入口关闭，已开窗口实时清除内容，服务端拒绝增减数量、整理、实例编辑、转移、穿脱、发起/接受相关交易。
   - 其他玩家可以查看公开玩家角色的背包和装备，通过“拾取”放入自己的未归零角色背包。默认物品库加入权限不影响拾取。
   - 接收方必须是自己的公开非 NPC 角色。满格、数量无效、版本过期、角色回血等返回错误，失败不会扣掉原物品。
   - 从装备栏取物会卸下指定部位；从背包取物优先使用未穿戴数量，不足时卸下必要部位，原角色属性重算。实例名称/备注和物品定义引用保留，待处理的相关交易取消。
   - 重复同一操作 ID 返回原结果；并发取同一物品只有一次成功，沿用现有事务和版本检查。
   - 回血后本人访问恢复，其他玩家失去拾取权限；GM 继续管理。NPC 保持原有“归零 + GM 允许搜索”的只读规则，没有给玩家新增 NPC 拾取权。

自定义人物使用配置的有效血条值；未配置血条时不按未使用的旧 currentHp=0 判定。限制以人物为单位，同账号另一名未归零角色仍可使用背包。

## 修改位置

- `packages/shared/src/character-access.ts`：归零、查看、拾取共享规则。
- `packages/shared/src/sheet.ts`：结构化数值来源。
- `apps/api/src/domain.ts`：快照权限及来源过滤。
- `apps/api/src/operations.ts`：人物独立复制、拾取事务、归零背包/装备与交易限制。
- `apps/web/src/ui/ConfigurableSheet.tsx`、`CharacterSheet.tsx`、`ValueSource.tsx`、`HoverInfo.tsx`：人物卡排序与来源。
- `apps/web/src/ui/Board.tsx`、`InventoryEquipment.tsx`、`TradePanel.tsx`、`ActivityLogs.tsx`：地图菜单、拾取界面和中文日志。
- `apps/web/src/permissions.ts`：使用服务端查看判定，避免隐藏生命字段造成误判。

本轮没有新增数据库表、迁移或基础设施；旧数据保留，原服务启动重算会补充来源缓存。
