# 角色状态与 GM 备忘（v3.2）

## 给角色添加标记

1. GM 打开人物卡，点击「管理状态」。角色目录也有同样入口；地图 Token 右键菜单可打开角色状态。
2. 点击「添加状态」，选择已有定义；或「新建定义并添加」，自由填写名称、选择图标/emoji、颜色及默认值。
3. 在同一浮窗填写「角色专属详细备注」，选择可见范围与优先级，点击「添加到此角色」。
4. 点击头像周围的图标查看完整详情。GM 可点「编辑此角色备注」，明确提交保存；玩家只能阅读有权查看的内容。

一个定义可以用于多个角色，但每条详情完全独立。定义里的「备注初稿」仅在分配时复制一次；之后修改初稿不改变历史备注。更新定义的名称、图标和颜色会更新所有引用它的徽章。

## 状态名称的罗马数字

新建或编辑状态定义、给人物添加状态、编辑已有角色状态时，可用「罗马数字」下拉选择无或 I–X。选中后在状态名称后显示金色古典字体数字，人物卡状态栏、悬停和详情同步显示；选择「无」清除后缀。

定义的数字作为新分配默认值，人物实例可独立修改，修改默认值不覆盖已有实例。数字仅作名称后缀，不改变词条加成或剩余回合。保存、刷新和人物复制均保留。见[实施与升级说明](state-roman-2026-10-18.md)。

## 三种可见范围

| 范围 | 谁能看到图标、名称及详情 |
|---|---|
| 仅 GM 可见 | 房间 GM |
| 角色控制者与 GM | GM、角色所属账号和获准编辑其他玩家角色的成员；NPC 此范围仅 GM 可见 |
| 全房间公开（新状态默认） | 能查看此角色的房间成员 |

隐藏角色仍遵守房间原有角色可见性。未授权状态不会下发给玩家，`+N` 只统计当前账号可见的状态。由公开改为私密后，其他玩家已打开的详情会更新为无权限提示。

## 长备注与保存

备注最多 100,000 字符，支持普通文本、换行、标题、粗体、斜体、列表、引用以及 HTTP/HTTPS 链接。HTML 按普通文字显示。点「预览备注」检查排版，再保存。

只有提交才保存和同步，不会每敲一个字广播。显示「保存成功」后数据才确认写入。保存失败时输入保留，可重试；另一个 GM 修改同一备注时，旧窗口会提示冲突，并提供「复制草稿」「重新加载」。重新加载会确认是否丢弃草稿。其他窗口移除状态时，GM 的编辑草稿仍可复制，但不能再保存到已移除实例。

浮窗关闭和浏览器刷新/关闭会保护未保存草稿；关闭时沿用未保存草稿保护。草稿不是离线数据库，长篇编辑请及时保存。连接恢复后自动读取最新已保存内容。

## 状态库、总览与批量分配

- 左侧「状态」打开 GM 状态库。可以检索名称、查看关联角色数、编辑定义、删除和恢复。
- 「角色状态总览」按角色、定义、可见范围和优先级筛选，搜索名称与详情全文；点击结果打开那条角色实例，可直接编辑或移除。
- 「批量分配」勾选多个角色，每个角色分别复制一份备注。已有同定义状态的角色跳过，原备注不会被覆盖。
- 优先级越大越靠前；最多显示 3 个头像图标，其余为 `+N`。点击 `+N` 打开完整可见列表。地图徽章使用同类符号，并保留 Token 拖动与原右键菜单。

「从此角色移除」会删除该角色的状态实例及备注，需确认；不会影响其他角色或定义。「删除状态」将它移出库的可分配列表，已有角色状态及独立备注保留；可勾选「显示已删除状态」后恢复。要移除人物卡上的状态，在该角色的管理状态中操作。

状态可添加自定义词条：数值名称与人物卡数值字段一致时自动加成，文字仅记录；移除状态撤销加成。备注不执行触发条件，也不自动扣血或改变战斗轮次。可点“从技能选择”复制技能为独立状态；技能模板原词条仅记录。详见[状态和背包说明](states-backpacks-2026-10-17.md)。

## 升级与恢复

本功能复用原数据库、API 和 Socket.IO；状态和长备注保存在数据库，图标不上传图片。

本地升级（先备份现有数据库）：

```powershell
pnpm --filter @dnd/api exec prisma migrate deploy
pnpm --filter @dnd/api exec prisma generate
pnpm build
```

新增迁移是 `202610100001_character_tags`，仅新增表、索引及外键。不要使用 `migrate reset`。Windows BAT 启动会运行 migrate deploy；更新前同时备份原数据库、图片和配置，见 [Windows Server 部署说明](windows-server-deployment.md)。

实机恢复验收：在备份副本中分别给 A/B 写超过 2,000 字的不同私密备注，再公开一条；重启 Windows BAT，核对 GM、所属玩家与其他玩家的图标/详情，确认 A/B 内容完整且不同，再检查旧人物卡、装备、状态、地图与剧情放映。早期实施证据见 [实施状态](character-tags-implementation-status.md)。

复现检查：

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm lint
# 本地 API、数据库、示例账号就绪后
pnpm --filter @dnd/api smoke:tags E
pnpm exec playwright test apps/api/e2e/character-tags.spec.ts
pnpm e2e
```

人物卡下方技能、状态和特性支持鼠标悬停或键盘聚焦查看完整说明、词条及特性启停状态，Esc关闭悬停卡。状态内容遵循当前账号可见范围，权限撤回后立即清除。

头像旁状态徽章、地图棋子的状态图标、顶部行动顺序栏中的状态也支持悬停查看完整说明、词条、罗马数字和剩余回合；头像/HUD可键盘聚焦，鼠标移入卡片可滚动长内容。点击仍打开详情浮窗。详情按名称、持续时间、说明、词条、管理操作分层排版，窄屏自动调整。见[状态详情与悬停说明](state-details-2026-10-18.md)。

## 有限状态与回合时间

状态库的「持续回合数」可选择永久或有限正整数，分配时复制为人物自己的「剩余回合数」，本次可覆盖；修改默认时间不改变已分配实例。人物状态详情可独立调整，列表、徽章悬停及总览显示剩余时间。

启用侧栏「回合系统」后，GM每次正式结束或跳过当前人物的回合，只将该人物的有限状态减一。归零会真正解除并撤销数值加成，永久状态不变；移出队列、结束模式不清空未到期状态。本回合中途添加默认在本次结束时扣减；重复同名定义沿用现有唯一规则，请编辑已有实例时间。完整步骤见[回合与时序系统](turn-system-2026-10-18.md)。
