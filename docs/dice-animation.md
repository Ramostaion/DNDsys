## 使用

进入房间，打开「骰子」，填写表达式并掷出。骰盘展示翻滚、落桌弹跳、阴影变化及短暂亮光，结果卡保留总和、修正和完整骰子明细。

- D4、D6、D8、D10、D12、D20 使用对应面数的立体模型。
- 百分骰及其他任意面数使用水晶造型，结果面展示真实点数；模型不模拟数百个面。
- 一次最多绘制 6 颗骰子，超过时提示总颗数；计算和明细仍包含全部骰子。
- 只有常数的表达式不会生成虚假的骰子。
- 本人点击掷骰时让骰盘进入视野；远端掷骰不会强制打开窗口或改变他人的滚动位置。

勾选「3D 掷骰动效」控制动画，选择保存于浏览器。系统减少动效设置始终优先。动画关闭后仍可直接看到点数。

## 结果与多人行为

动画读取原有服务器掷骰结果，不生成随机点数，也不改变总和、角色资源或记录。等待期间只显示符号，失败后停止等待并显示错误，允许重试。

已打开骰盘的成员收到新可见结果时播放落定效果。玩家私密结果只给本人和 GM，GM 私密结果只给 GM。重新打开窗口或刷新读取旧记录时静态展示，不重播历史动画。

采用浏览器原生 CSS 3D，不增加渲染或物理引擎依赖，不修改数据库和服务器掷骰接口。画面是按返回点数定向的展示动画，碰撞和弹跳由动画控制。
