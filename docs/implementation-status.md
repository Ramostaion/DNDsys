## G2 数据权限、物品与多人操作

- [x] 新增公开/仅 GM 地图、角色和 Token 可见性，快照同时过滤相关入口、绘图、战斗引用和日志；玩家对私密地图绘画或移动私密 Token 返回 403。旧数据迁移默认公开。私密地图要求新图片使用私密上传路径。
- [x] 物品定义可编辑，装备后更新可触发重算；背包实例可单独改名、记备注及修正值，不改变公共定义。交易采用请求、接收方确认和数据库原子转移，重复确认被拒绝；操作 ID 幂等与版本冲突返回明确状态。
- [x] 三账号真实 API 脚本验证了私密字段/地图/角色/Token、实例覆盖与恢复、跨所有者交易及版本冲突。
- [x] 房间可切换自由/混合/受控模式，分别控制人物卡数值、经验等级、模板安装、公共物品编辑和玩家交易；GM 可设置成员例外，后端执行而非只禁用按钮。真实 API 覆盖三种模式及成员允许/禁止覆盖。旧房间默认混合模式以保持原行为。

## G3 通用人物卡、公式和被动数值

- [x] 房间字段有稳定 ID、显示名、类型、分组、顺序、默认值、资源上限、可见性和编辑权限；字段值独立保存。更改显示名不影响引用，删除被公式引用或有角色保存值的字段会被阻止。
- [x] 共享安全公式解析器支持 `{{fieldId}}`、四则运算、比较、`if/min/max/round/floor/ceil/abs`；拒绝未知/非数值引用、循环、非法函数、除零和越界。公式字段只读，来源解释可见，私密字段不能流入更公开的公式。
- [x] 装备、特性、Buff 支持 `ADD/MULTIPLY/OVERRIDE` 修正；启用/关闭、穿戴/卸下、模板或物品定义更新后重算。共享模板更新会传播，独立副本保持当时值。真实 API 场景覆盖防御、力量依赖、魂力及实例覆盖。
- [ ] 公式值本身作为 Modifier、模板迁移预览、旧人物卡的交互式转化、字段拖放布局未完成。字段预览目前覆盖公式计算，未覆盖全部存量角色的迁移影响。
