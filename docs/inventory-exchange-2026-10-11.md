# 背包与装备双向转移 · 2026-10-11

## 已实现行为

- 玩家生命归零后，本人仍不能打开或操作该角色的背包和装备。
- 其他玩家可在“自己的未归零角色”和“公开归零玩家角色”之间双向取放：背包到背包、装备到背包、背包到装备、装备到装备。也可在归零角色背包内部整理位置，或用装备下拉框穿脱其已有物品。
- GM 可打开任意角色的背包/装备，在窗口间直接拖动，包括归零角色和仅 GM 可见的角色。普通玩家对 NPC 仍只能按原搜索规则查看；对其他未归零玩家不增加直接转移权限。
- 跨角色拖动每次转移一件，拖到背包空格保留目标格位置；批量转移可选择物品后使用“转移给角色 / 转移目标位置 / 转移数量 / 转移物品”。装备栏中每件穿戴物也有转移按钮。
- 取穿戴装备时自动卸下指定部位；背包堆叠物品优先使用未穿戴数量。放入装备部位时直接穿戴，自动重算相关人物数值；被替换的旧装备留在原人物背包。
- 装备仍引用背包实例，沿用原项目数据模型；跨角色直接放入装备也需要接收背包有空格。相同角色穿脱使用现有实例，不复制数量或额外占格。
- 名称、实例备注、物品定义引用与剩余数量保持；物品相关待确认交易取消，防止旧交易再转走已经移动的物品。
- 背包满格、目标格被占用、装备部位不兼容、过期版本或目标人物回血时，整次操作失败并保留原物品。重复操作 ID 返回原结果，并发继续由现有事务及版本处理。

## 使用方法

1. 打开人物 A 的人物卡，点“背包”或“装备”。关闭人物卡不会关闭背包/装备窗口。
2. 打开人物 B 的人物卡，再打开其背包或装备，将两个窗口拖到左右两侧。
3. 拖动背包物品格，或装备栏内的物品图标，到另一窗口的空背包格/兼容装备部位。
4. 不便拖动时，在背包选择物品，使用下方转移控件；装备物品也提供相同控件。选“背包”放入空格，选具体装备部位直接穿戴。

取走后可以按同样方式反向放回。普通玩家的这项双向权限会随归零角色回血撤回，GM 不受限制。原物品库新增物品仍需独立授权。

## 实际改动

- `packages/shared/src/character-access.ts`：双向归零交换规则。
- `apps/api/src/operations.ts`：共用现有转移处理，兼容旧拾取操作；支持来源装备部位、目标装备部位、指定背包格、同角色穿脱和归零角色整理。
- `apps/web/src/permissions.ts`：转移目标与拖动权限。
- `apps/web/src/ui/InventoryEquipment.tsx`：背包与装备拖动、目标角色/部位/数量控件，移除重复的单向拾取 UI。
- 共享规则单元测试与 `apps/api/e2e/usability-fixes.spec.ts`：真实双浮窗拖拽、按钮及权限/回滚回归。

没有增加数据库表、迁移、基础设施或独立安全框架，旧物品和装备关系保留。
