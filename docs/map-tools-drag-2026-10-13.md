# 地图工具拖动

日期：2026-10-13。

## 使用

- 按住地图工具标题栏拖动，标题旁有拖动图标，光标显示抓手。
- 单击标题仍然折叠/展开；折叠后的标题也能拖动。拖动超过 4 像素后抑制该次点击，避免松手时误折叠。
- 量尺、画笔、擦除、形状与距离等内容操作保持原功能，不会开始拖动工具或平移地图。
- 每个账号在每个房间的位置保存在浏览器本地，刷新后恢复，其他玩家的位置不受影响。未保存位置时仍默认在左下角。
- 拖动限制在地图主视窗边界内，窗口或工具尺寸变化时自动调整；极小高度仍保留可操作的标题。损坏/不可用的本地存储不会阻止拖动。

## 实现与文件

- `apps/web/src/ui/MapToolsPanel.tsx`：独立工具容器，标题 Pointer Events、指针捕获、拖动/点击区分、位置保存、ResizeObserver 边界恢复。
- `apps/web/src/ui/map-tools-position.ts`、`.test.ts`：有限坐标恢复与边界计算。
- `apps/web/src/ui/Board.tsx`：接入容器与标题图标，并在房间/账号切换时读取对应折叠状态。
- `apps/web/src/style.css`：抓手、拖动抓紧、标题防误选与触摸行为。
- `apps/api/e2e/usability-fixes.spec.ts`：实际拖动及现有折叠回归。
- 本记录与项目修改总记录。

仅前端改动，无数据库迁移、后端接口、同步事件或依赖调整。生产部署重建前端，开发模式刷新即可。

## 真实验证

- 35/35 前端单元测试通过（包括两项位置恢复/边界场景）；前端生产构建包含类型编译通过，全项目代码及格式检查通过。
- 2/2 定向联机（13.7 秒）：GM/玩家拖动及独立位置、展开/折叠拖动不误切换、鼠标单击与键盘 Enter 折叠恢复、量尺形状/距离仍可操作、地图坐标没有因工具拖动改变、刷新位置恢复、拖到边缘与实际缩小视窗后保持边界；原右上骰子位置、工具大小及折叠回归通过。
- 测试房间及账号残留均为 0，用户原数据库、网页和 BAT 服务保留，没有关闭用户窗口。
- 未重跑 API/共享层单元或完整联机套件；NAS/异地实机、触屏与全部浏览器未验证。
