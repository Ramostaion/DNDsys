# GM NPC 目录管理

日期：2026-10-22。修改当前使用的桌面 ProjectDND-GitHub 副本。

## 启用与使用

本次新增后台功能和第30项数据库迁移。关闭并重新双击「启动跑团.bat」，启动完成后让成员刷新网页；启动器会应用未执行的增量迁移。本机已经应用 `202610220001_npc_directory` 并检查状态，无 reset、seed 或旧数据删除。本轮没有停止用户正在运行的5242服务，也未推送GitHub。

GM 打开「角色 → NPC」，默认是左侧目录树、右侧列表。角色窗口默认780×640，可手动调整；较窄时目录改在上方，也可用「收起目录」让列表占满窗口。

1. 「新建根目录」建立顶层分类；选中目录后用「新建子目录」。多层目录按稳定ID关联，名字可改，展开状态按房间和账号保存在当前浏览器。
2. 选中目录后可重命名、↑/↓调整同级顺序、用「移动目录」整体迁移子树。不能移到自己或后代，也不能同级重名；名称会去首尾空白。
3. 「全部 NPC」列出房间全部 NPC；「未分类」只列未归类 NPC。默认包含子目录，可关掉仅查看当前目录。面包屑可返回任意上级。
4. 在具体目录中创建 NPC 自动归入这里；在全部/未分类入口创建则归未分类。公开/隐藏仍由原可见性开关决定，不从目录继承。
5. 每张卡可单独「移动到…」；也可勾选多个或本页全选，再「批量移动到…」。选「未分类」清除归属。头像、状态徽章、人物卡及拖到地图放置棋子沿用原功能。
6. 搜索支持当前目录/全部NPC。当前范围遵守包含子目录开关；统计、每页12个和空状态均按筛选结果计算。每张卡底部显示完整目录路径，点击可定位并清除搜索。
7. 删除前会显示直接子目录数和直接 NPC 数，可选移至上级或根级。只删除目录本身，子目录整体保留，NPC不会删除。NPC移至根级就是未分类。同名冲突会拒绝整次操作，先重命名后重试。
8. NPC转为玩家角色会清除分类；玩家角色转NPC默认未分类。删除NPC按原规则执行，分类随之清理。另一GM删除当前目录后安全退回全部NPC并提示；失败不清空操作表单，可重试。

普通玩家继续查看已公开的 NPC，没有目录树、目录路径、分类关系或目录统计。目录只用于GM管理，不改变公开状态、控制权、人物数值、装备、状态、战斗记录或地图棋子。

## 实现与数据

- 新增 `NpcDirectoryState`、`NpcFolder`、`NpcClassification` 三张独立表；旧NPC不需要回填，缺少分类记录即未分类。分类关联人物ID，删除人物级联清理；目录的删除必须先迁移直接成员。
- 查询 `GET /api/rooms/:roomId/npc-directory` 在服务端验证房间成员与GM身份。房间快照只为GM附加 `npcDirectory`，普通玩家连该键也不返回；目录活动日志在玩家查询中排除。
- 写入复用 `POST /api/rooms/:roomId/operations`，新增 `npcDirectory.create/rename/sort/move/delete/assign`。载荷要求目录 `version`；移动/分类目标用 `parentId`（null为根或未分类）。`character.create` 可带 `npcFolderId`。
- 目录写入使用现有房间 `FOR NO KEY UPDATE` 锁、Read Committed事务、OperationReceipt请求ID去重和独立目录版本。角色创建/转换/删除也参与该锁，保留原角色事务的Serializable隔离。目录事务内再次确认GM身份，同级名称在应用层和数据库均受约束。
- 目录变更通知通过现有GM私有通道发出 `change` / `npcDirectory.changed`，只有操作ID，不广播目录正文。原Socket连接触发GM重读快照，重连与窗口恢复沿用原机制。旧版本目录快照不能覆盖新版本；没有重挂载人物卡或修改其草稿生命周期。
- 不增加服务或运行依赖，不修改原NPC字段，也不把目录名称用于业务关联。未加入目录拖拽，避免与NPC拖到地图混淆。

- 新功能最终两项联机通过，随后与剧情放映、背景音回归同轮 **5/5（51.4秒）**。包括多层创建/改名/排序/移动、同级重名、循环/跨房间拒绝、双GM竞争只能提交一次、同ID并发只记一次、批量分类、两种删除去向、NPC/玩家类型转换、NPC删除清理、后台实例重建后完整目录一致。

- 实际UI验证14个初始NPC的分页、包含子目录、名称搜索及路径定位、选中目录创建、勾选移动、多GM刷新、模拟503保留输入并重试、展开状态刷新恢复、当前目录被远端删除后回退、状态徽章保留、真实打开人物卡及未离焦名称草稿保持、NPC拖放的原characterId载荷和服务端地图Token落库。已查看实际左右栏截图，验证收起/展开目录栏。
