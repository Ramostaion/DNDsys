# 同行者摘要、日志、弹窗与地图入口改进

日期：2026-10-11。

## 完成内容

1. 自己的角色摘要及生命值移动到右上同行者栏下方，跟随栏高排列；角色悬停详情向左展开。地图 Token 的血条继续保留。
2. 活动日志改为中文事件，并为每条记录提供展开／收起箭头。展开后显示操作成员、时间、关联对象；有字段变化记录时展示原值和新值。旧日志未保存的具体变化不凭空补写。
3. 通用功能弹窗支持四边及四角拖动缩放。剧情浮窗复用同一缩放控件，并保存个人大小与位置。标题栏仍可移动，最小化、关闭及草稿保护保留。
4. 入口详情补上「跳转到该地图」，GM 切换后同步到所有玩家；「在地图册查看」打开对应地图详情，那里同样有切换按钮。
5. 地图册可直接选择所有可见地图及子地图。创建入口从已有地图中选择目标，入口独立于地图层级。GM 可移动入口、删除入口；删除入口保留目标地图。删除父地图保留子地图并将其移至根目录。

- 沿用现有地图、入口、活动日志及窗口结构，没有新增数据库迁移或基础设施。
- 保留旧地图、入口、日志和角色数据；本次测试使用临时测试房间。
- 地图激活、入口创建／移动／删除仍仅 GM 可执行；玩家可查看有权限看到的入口详情。
