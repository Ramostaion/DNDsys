# 剧情导演台背景音

日期：2026-10-21。修改当前实际使用的桌面 ProjectDND-GitHub 副本。

使用说明已包含同日后续调整；末尾保留本次修改与实际验证。

## 使用

1. 更新代码后关闭并重新双击「启动跑团.bat」，等待启动完成；所有成员刷新网页。启动器应用第29项增量迁移，不清空旧数据。本机已经应用并检查迁移状态。
2. GM 打开导演台顶部「剧情背景音」，上传文件、选择曲目，点击「向全员播放」。推荐 MP3；支持 MP3、WAV、OGG、M4A、WebM，单个最多100MB，具体编码仍需浏览器支持。
3. GM 可暂停、继续、停止、拖动进度、循环、调整房间音量、重命名或删除曲目。关闭导演台、切换剧情图片、黑幕或结束图片放映不会停止音乐，请用「停止背景音」结束。
4. 玩家在同行者下方调自己的音量或静音，不影响其他人。默认自动尝试播放，不再需要开启按钮。浏览器若限制自动播放，下一次点击页面或键盘操作会自动接入当前进度；完全没有交互时无法强行绕过浏览器限制。音量与静音偏好保存在当前浏览器。
5. 个人音量悬浮窗常驻主视窗右侧轮数下方（没有回合时在同行者下方），未播放也可调节；图片沉浸观看和窄屏下，右上角直接显示小面板；不会强制打开模态窗口或改动正在编辑的人物卡。
6. 刷新、晚加入和掉线重连读取服务器当前曲目和进度；断线暂停，重连后追到当前进度。公网延迟、音频加载和设备差异会影响同时出声的精度，不承诺采样级同步。

## 数据与部署

新增 RoomAudioTrack 保存曲目元数据；原 PresentationSession 增加独立 audioRevision 和 audio JSON。播放、暂停位置、开始时间、循环与房间音量写入原数据库，重启后台继续按服务器时间计算。非循环自然结束按时长投影为停止，不需要后台轮询任务。

文件保存在原 UPLOAD_DIR 下的「房间ID/audio」目录；上传按磁盘流接收，浏览器原生解码和播放，支持 HTTP Range。数据库和整个上传目录需要一起备份/复制到服务器。音频文件、真实配置和数据库仍被 Git 忽略，不会随源码上传。

没有新增运行依赖、服务或音频引擎。GM 未提供时长时，由 GM 浏览器解码后补存时长；无法解码时显示重试提示。删除正在播放的曲目会停止全员背景音。

## 事件及接口

复用现有 Socket.IO 房间连接，新增 presentation.audio.changed，载荷为 roomId、可选 revision/library，只通知刷新；客户端重读持久化状态。图片放映版本独立，避免音乐操作覆盖图片切换。

接口前缀：/api/rooms/:roomId/presentation/audio。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | /current | 房间成员读取当前状态、曲目和服务器时间 |
| GET / POST | /tracks | GM 列表/上传 |
| PATCH / DELETE | /tracks/:id | GM 改名、补存时长/删除 |
| GET | /tracks/:id/file | 音频与 Range；玩家只能读取当前曲目 |
| POST | /commands | GM play/pause/resume/stop/seek/settings |

控制沿用房间行锁、版本检查和 OperationReceipt 请求ID去重。冲突返回409并刷新，不将多个旧命令排队。通知失败不删除已提交的上传文件；重新连接/聚焦读取数据库恢复。

## 2026-10-22：放映时音量窗与玩家列表重叠修复

原因：此前剧情会话只要不为idle，就把个人音量窗挂到页面顶层，并使用固定top:60px；GM的浮窗预览、已关闭个人观看窗但放映仍继续等情况，也会触发该定位，覆盖玩家列表。之前测试只验证放映前/结束后在轮数下方，遗漏放映期间的几何位置。
