- C：已实施，本地恢复验证通过，NAS 实机验收未验证。图片复用 sanitizeImage、sharp 缩略图和原上传卷；先写文件再保存附件，失败补偿删除本次文件；发送前确认文件可读。私密读取须为 GM 上传者或有效投递接收者，未公开图片不能通过旧公共上传地址取得。阶段 C 浏览器测试 1 / 1 通过：上传失败／重试保留文字及接收人、发送响应丢失后同 ID 重试不重复、仅接收者可读图、图片加载失败重试、滚轮缩放、适应窗口、Esc、刷新恢复；独立真实 API 进程停止再启动后图片字节和已读记录一致；非法图片拒绝、已引用附件不能删除、丢失文件时整个发送事务回滚。首次测试因中文附件文件名被 multipart 解码为乱码失败，修复并增加单元测试后复测通过。Compose 的 db-data / uploads 卷及 API 启动迁移已核查，无需改动；没有 Docker / 群晖环境，不能声称容器构建或 NAS 重建通过。

## 主要变更与接口

- 新增 `apps/api/src/private-clues.ts`、输入校验及测试，Schema 的四个模型和新增迁移；`index.ts` 注册独立模块与 `privateClue.changed` 定向账号通知。
- 新增 Web `ui/private-clues/`：收件箱同步 Hook／Context、浏览器草稿、投递／阅读／图片组件及 CSS；`App.tsx`、`Windows.tsx`、`store.ts` 接入原窗口与侧栏，导演台增加私密投递入口。
- 增加 `apps/api/e2e/private-clues.spec.ts` 四账号真实服务验收；放映测试使用精确「线索」匹配，避免新增「私密线索」入口造成定位歧义。
- 根路径 `/api/rooms/:roomId/private-clues`：`POST /send`（操作 ID）；`GET /inbox`；`GET/PATCH /deliveries/:id`；`GET /sent`、`GET/PATCH /sent/:id`；`POST /deliveries/:id/forward`（操作 ID）；`POST /attachments`、`POST /attachments/from-presentation`、`GET /attachments/:id/thumb|original`、`DELETE /attachments/:id`（仅未引用附件）。
- 私密模块不写公共 ActivityLog、不广播 `change` 或正文、不调用人物重算、战斗、标签或放映控制。分享复制内容快照并引用已保存的不可变私密附件；剧情素材导入则复制独立文件。

## 运行与迁移

本机 BAT 现有步骤会自动应用迁移和生成客户端。手动：`pnpm --filter @dnd/api prisma migrate deploy`、`pnpm --filter @dnd/api prisma generate` 后启动项目。Docker API 镜像构建生成客户端，启动自动应用迁移；Compose 服务与卷无需改动。迁移已在本机原数据库应用，不删除任何旧表或字段。
