# 产品边界（v3.0）

依据项目根目录 `ProjectDND_Codex_全面升级执行提示词_v3.0_人工裁决版.md`。

- 万象跑团是多账号协作的通用 TRPG 数字桌面。每个房间可定义自己的角色字段、公式、数值资源和模板；六维、经验、HP、AP、SP 只是可选预设。
- 服务端负责权限、持久化、并发控制、数值公式与安全掷骰。命中、伤害、技能使用、行动合法性、资源消耗、状态到期均由玩家与 GM 裁决并明确记录。
- 掷骰与推进回合不修改角色数值。装备、特性、Buff 的被动修正只重算数值，不执行战斗动作。
- 掷骰默认房间公开，也可在掷出前选择私密；玩家私密骰由本人和 GM 查看，GM 私密骰仅 GM 查看。私密结果不会进入其他玩家的快照或实时通知。
- 旧角色、物品、房间、图片与自动攻击历史须保留。旧自动战斗入口应改为手动记录；旧数据以来源标记继续可读。
- 字段标识与显示名分开，改名不能打断公式；公式不执行用户代码，不把错误结果悄悄替换成零。
- 公开、GM 私有内容在服务端过滤。前端隐藏不构成权限边界。

旧版 `README.md` 中的自动攻击说明仅描述历史实现，不再代表产品目标。
