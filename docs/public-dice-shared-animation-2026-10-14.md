# 公屏骰子复用命运骰盘与淡出

日期：2026-10-14。在现有公开骰子事件与服务器冷却之上调整前端表现。

## 当前效果

- 公屏直接使用命运骰盘的 DiceStage，复用骰型几何、实际结果朝向、die-settle 翻滚、die-bounce 弹跳和落地阴影；移除公屏原先独立的简化立方体。
- DiceStage 增加可选 compact 模式，只缩小公屏尺寸和隐藏重复标题/说明，原骰子窗口保持完整骰盘样式。常用骰型、任意骰面和最多 6 颗绘制限制继续复用，所有展示点数来自服务器。
- 从服务端掷骰时间计，约 1.5 秒后显示总结果；约 4.45 秒开始淡出，350 毫秒后移除。淡出期间仍保留点数，时钟沿用已有 serverNow 与浏览器单调计时。
- 减少动态效果设置禁用旋转、落地和淡出动画，直接显示结果，随后移除。
- 公屏及其子元素不接收鼠标输入。公开骰与战斗广播同时出现时，将战斗广播位置下移，给最多 6 颗骰子的演出留出空间。
- Socket.IO、公开两秒房间冷却、私密范围、数据库与历史恢复没有改动；新演出取代前一条的行为保持。

## 修改文件

- apps/web/src/ui/dice/PublicDiceBanner.tsx：使用共享 DiceStage，结果/fading/hidden 生命周期及计时器清理。
- apps/web/src/ui/dice/DiceStage.tsx、dice-stage.css：compact 公屏尺寸，复用原几何及动画。
- apps/web/src/ui/dice/public-dice.css：删除独立骰子样式，新增透明度和轻微上移的淡出动画，保留居中/非模态/减少动态效果。
- apps/api/e2e/public-dice.spec.ts：共享骰子面/实际点数/相同动画、淡出阶段/移除以及减少动态效果验证。
- README.md、本文、项目修改总记录.md：当前行为与测试记录。

## 实际验证

- 前端 **43/43 单元测试通过**，包括现有常用骰型几何、真实点数、绘制上限、历史公式及计时器单调计时检查。
- 前端生产构建（含类型编译）、全项目代码与格式检查通过。
- 公开骰独立真实浏览器联机 **1/1 通过（23.9 秒）**：四个账号/两个房间、非安全 HTTP 环境，GM/玩家同步，公屏每颗结果与服务器相同，两颗 D6 共 12 面，公屏与命运骰盘使用相同动画名称，结果后确实进入 public-dice-exit 淡出阶段并移除，减少动态效果客户端没有动画。
- 该场景还验证公开冷却、两人同时请求、请求去重/丢失回复重试、私密隔离、房间隔离、刷新/重连不重播、数据库历史及测试 API 实例重建恢复，人物卡草稿保持可编辑。
- 已查看 .launcher/public-dice-desktop.png 与 .launcher/public-dice-player.png，桌面/900 像素视窗下居中、数值和计算可读。
- 复用并保留用户原服务，仅测试用 API/网页实例按测试清理。没有新增依赖、数据迁移或基础设施。
