# 状态详情布局与悬停阅读

日期：2026-10-18。

## 界面

状态详情改为清晰的阅读层次：

1. 顶部是与状态颜色呼应的图标、名称、金色罗马数字与所属人物。
2. 名称下方统一展示剩余回合或永久，以及当前可见范围。
3. 「状态说明」使用独立深色阅读区域，保留Markdown、列表和安全链接。
4. 「状态词条」分列展示，数字使用明确正负号；窄屏改为单列，长文字自动换行。
5. GM编辑、管理和移除操作放在正文之后，主要编辑突出，移除单独弱化；最后修改时间及GM展示优先级收在底部。玩家只读，原操作权限、确认及错误反馈保留。

弹窗与悬停共用 `StateDetailsContent.tsx` / `state-details.css`，不再分别拼接说明和数值，状态库和人物独立备注仍按原规则保存。

## 悬停入口

- 人物卡、角色目录的头像旁状态徽章：悬停或键盘聚焦后显示完整详情；点击仍打开状态详情浮窗。
- 地图棋子头像旁状态图标：悬停显示同样的详情，按图标在屏幕中的位置放置；点击仍打开原浮窗，拖动和地图操作保留。
- 顶部行动顺序栏的有限状态：悬停或键盘聚焦查看完整内容，倒计时继续使用权威快照。
- 人物卡下方状态栏原有悬停也使用新的内容布局，技能和特性的原详情保持。

保留原180ms出现、120ms离开延迟，鼠标可以移入卡片阅读和滚动，Esc关闭。卡片限制视窗边界和最大高度，长备注可滚动，不挤压地图或其他窗口；悬停本身不提交操作、不改变状态或回合。

地图缩放、拖动、工具/地图切换会关闭旧卡；缩放以鼠标位置为中心，若鼠标仍在同一图标上，离开后重新进入会显示新位置的卡片。

所有内容都从当前账号的最新权限快照解析。撤回公开权限、移除状态、隐藏人物或切换地图后，相应旧预览不能继续显示，不缓存被撤回的正文。

## 实现范围

- `CharacterTagDetails.tsx`：重排详情，原编辑/管理/移除逻辑保留。
- `StateDetailsContent.tsx` / `state-details.css`：统一只读展示、图标与标题、时间/权限、说明、词条及悬停外观。
- `CharacterTagBadges.tsx`、`Board.tsx`、`turns/TurnHUD.tsx` / `pages/Room.tsx`：接入头像、画布和HUD的最新状态数据。
- `HoverCard.tsx`：在原定位体系中支持画布虚拟锚点，默认仍是HTMLElement，背包原有调用保持兼容。
- `CharacterAbilityDetails.tsx`：状态分支共用新内容，技能/特性分支保留。
- `ability-details.spec.ts`：扩展实际鼠标/键盘、三入口、权限、窄屏与截图验证。
