# 状态名称的罗马数字后缀

日期：2026-10-18。

## 使用

状态库新建或编辑定义、给人物分配状态、编辑人物已有状态时，都可以选择「罗马数字」：无、I、II、III、IV、V、VI、VII、VIII、IX、X。

选中后，名称旁显示金色古典衬线后缀，例如「灵光祝福 IV」。下拉框旁的预览立即变化；提交保存后，人物卡状态栏、悬停详情、状态详情、状态管理列表及 GM 总览同步更新。头像徽章的名称提示和回合 HUD 提示也带上该数字。

「无」清除后缀。使用金色 `#D4AF57` 与 Palatino / Book Antiqua / Georgia 系统衬线字体，不增加字体下载或循环动画。

状态定义保存分配默认值，添加到人物时复制一份，人物实例可以独立修改。例如默认 III 的状态可分别给两个人物设成 II 和 IV。之后更改定义默认数字不会覆盖已经分配的人物状态。

数字只修饰名称，不表示自动叠层或词条倍数，不改变基础数值、状态效果、剩余回合或到期规则。数字与剩余回合分别显示。

## 保存与权限

- `TagDefinition.romanNumeral` 保存默认值，`CharacterTag.romanNumeral` 保存实例值；空字符串表示无。旧数据升级后为无。
- 客户端与服务器使用同一份 I–X 选项，数据库另有 CHECK 约束，拒绝 XI 等非法值。
- 旧客户端更新时不传这个可选字段，会保留现有值；明确传空字符串才清除。人物复制一并复制实例数字。
- 继续使用原状态操作、版本检查、事务、回执、Socket 通知和权限快照。GM 才能编辑，玩家仅阅读当前有权查看的状态。没有新增接口或逐帧全局状态更新。
- 已有未保存草稿保护、多人编辑冲突及重新加载逻辑包含新字段。
