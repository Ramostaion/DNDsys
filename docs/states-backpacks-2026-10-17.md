# 角色状态、技能词条和胸部背包 · 2026-10-17

## 使用

- 人物卡的“管理状态”、状态库、状态详情、地图菜单和徽章统一使用“状态”。新建状态默认“全房间公开”；已有私密状态保留原范围。
- 能力模板库的“技能”可添加文字或数值自定义词条。技能中的词条只记录资料，安装技能也不增加人物卡数值。
- 添加状态、分配状态及编辑角色状态时可添加相同的自定义词条。数值词条名称与人物卡数值字段名称一致时，按装备的同名词条规则加成；公式字段使用加成后的基础值计算。文字仅记录，重名或空名不能保存。移除状态即撤销加成。
- “从技能选择”将技能名称、说明和词条复制为一条公开的独立状态。后续编辑角色状态不修改技能；技能模板更新也不覆盖这条独立状态。此操作由原状态管理权限（GM）控制。
- 人物卡底部“特性”以及点击“技能”打开的能力窗口中，均有对角色控制者开放的启用/停用按钮。新安装默认启用；共享模板更新保留手动停用，也将未设置启停值的旧实例视作启用。技能安装、移除、角色基础值及特殊机制仍遵守原权限。
- 物品种类可选“背包”，自动提供数值“格数”。填2即装备后增加2格，只增加一次，不受物品堆叠数量放大。必须填非负整数。普通物品即使有同名词条也不扩容，未装备背包不扩容。
- 胸部区域分为“护甲”和“背包”两个位置，可同时使用。背包只能放入胸部的背包位，胸甲不能放入背包位。原有装备位和双手武器保持原规则。
- 容量等于原力量容量（缺少力量则用原容量）加已穿戴背包格数。背包修改、卸下、交换、跨角色转移都会在服务器重新计算；满包卸装按原事务整体回滚。物品词条变小导致超载时仍保留原物品，使用原待整理区。
