# 地图整笔擦除

日期：2026-10-15。

## 使用行为

- 在地图工具选择“擦除”，点击笔画任意一处可移除整条连续笔画；按住鼠标拖过多笔可以连续擦除，松开鼠标后统一提交和同步。
- 每次按下到松开画笔产生的 STROKE 记录就是一笔，不按颜色、连接点或相交关系合并。擦除一笔不会改写其他笔画的路径。
- 本机即时预览整笔消失，服务器接受后其他成员同步。请求失败会刷新并恢复画面，允许再次擦除。按 Esc 或窗口失焦可取消尚未提交的本次擦除；离开地图时提交，切换地图/工具时取消未提交部分。
- 移除橡皮大小输入，保留画笔粗细与颜色；命中采用实际渲染曲线的画布检测，约12px屏幕拾取宽度，并沿快速鼠标移动每约4px补采样，适应地图缩放和平移。
- 仅绘画层 STROKE 可被命中；擦除模式下角色/入口/量尺层不接收地图指针操作，避免误拖动或删除。退出橡皮后恢复原交互。
- 沿用绘画权限：GM 和已获得绘画权限的玩家可擦除可见公开地图笔画，未授权玩家不可操作，私密地图仅 GM。量尺仍使用原创建者/GM的独立删除规则。

## 后端与旧数据

新增原操作接口类型 `drawing.erase`，载荷为 `{ mapId, ids }`，单次最多2000条 ID。后端验证成员绘画权、地图可见性、房间/地图归属与 STROKE 类型，混入量尺、旧 ERASER、其他地图或房间时整批拒绝。

以现有 `undone=true` 逻辑删除，不删除笔画数据和坐标；同笔重复擦除可正常返回，原 OperationReceipt 防止相同操作 ID 重复执行。此操作采用 READ COMMITTED，按未擦除条件批量更新，使多人同时擦除同一笔也能接受；不添加队列或锁服务。

使用原房间 change 通知与快照同步，无逐帧擦除消息。原像素 ERASER 数据继续按 destination-out 渲染，已有地图外观保持；新橡皮不再创建像素遮罩。无数据库迁移、seed/reset 或原游戏数据重置。
