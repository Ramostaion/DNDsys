# 多人地图棋子移动演出

后续视觉增强：[淡金色方向箭头与虚线](movement-arrows-2026-10-15.md)。以下保留本轮基础实现及验证记录。

日期：2026-10-15。增量复用 React Konva、现有房间 Socket.IO、操作事务与 OperationReceipt，不新增依赖、数据表或数据库迁移。

## 当前表现

- 发起窗口正常拖动棋子，松开后保存；不播放自己的回放。同一账号的另一窗口仍是观察者，能够播放。
- 其他有权限的窗口在提交成功后播放约 600–800ms 演出：120ms 轻微抬升/放大和柔和阴影，300–500ms 平滑滑行，180ms 落地回弹和淡金色涟漪。最多四个低透明度头像残影，无持久路径或粒子。
- 残影在同层所有棋子及其名称、生命/护盾与标签下方；所有特效不接收鼠标事件，原量尺层仍在人物上方。
- 当前只保存地图世界坐标的起终点，采用 A 到 B 的直线插值，没有采集或伪造鼠标绕行路线。地图缩放和平移不改变世界坐标。
- 浏览器减少动态效果、后台页面或错过版本时直接恢复确认落点；不会回放旧历史。被遮挡窗口可能暂停 RAF，额外到时归位兜底保证最终状态。

## 协议与可靠性

原接口仍为 `POST /api/rooms/:roomId/operations`，类型 `token.move`，载荷仍为 id/x/y/version。发起窗口为每次拖动分配唯一操作 ID，使用原 OperationReceipt 去重，复用同一 ID 重试不会重复写入或广播。

移动事务从数据库读取真实起点与可见范围，校验控制权限、活动地图和版本，再条件更新坐标及版本；响应附带 movement，不接受客户端伪造起点或操作者。正常请求返回的 token 顶层字段保持兼容。

提交后通过原 `change` 通道增加 `token.moved` 子事件，字段包括 eventId、roomId、mapId、tokenId、characterId、actorId、version、from、to、completedAt、serverNow。只有成功且非重复的操作广播；广播失败不将已经落库的移动变成失败响应，后续快照仍能恢复。

隐藏 token、隐藏角色或私密地图沿用快照的三层可见条件，仅 GM 通道可收到坐标。公开移动只在所属房间广播。客户端仅已挂载的可见棋子订阅，没有历史事件缓冲区，不在重连时重新演出。

客户端在通知刷新快照前启动动画，用独立显示位置接续到服务器确认目标；同版本快照不会先把头像画到终点。新的移动从当前显示位置接续，旧版本和重复事件忽略；更高版本快照、断线、隐藏页面、移除棋子或切换地图会停止旧演出并恢复适当状态。发起端请求失败会刷新快照并回归确认位置。

## 实际验证

- 全项目类型检查、共享/API/网页生产构建、Brotli/gzip 生成、代码及格式检查通过。保留旧哈希资源以兼容当前已打开页面，正式构建缓存已更新。
- 单元测试 **124/124**：共享 48、API 31、前端 45。新增两项覆盖房间隔离、事件/本地操作去重、过期及非法事件、无历史缓冲、订阅清理，以及直线插值、单调运动、精确落点与最长时长。
- 新移动联机场景 **1/1（16.0 秒，整轮 17.2 秒）**：独立临时服务使用真实数据库、编译网页、Socket.IO 和六个独立浏览器上下文（五个账号，其中一个在其他房间；GM 另开相同账号窗口）。覆盖真实 GM/玩家鼠标拖动、其他窗口逐帧中间位置、无先瞬移再回起点、残影与涟漪、自己的窗口不回放、减少动态效果、数据库与落点相同、请求重试不重复广播、连续移动接续、缩放/平移、断线和刷新恢复、失败拖动复位、编辑草稿保留，以及三层隐藏和房间隔离。
- 在原 5242 服务上另行运行现有回归：量尺颜色/创建者/四种形状吸附与置顶/删除及重试 **1/1（9.9 秒，整轮 11.1 秒）**；地图工具拖动/记忆位置/折叠/控件/边界 **1/1（5.1 秒，整轮 6.4 秒）**。这两项使用新网页和原运行中后台；新移动协议由上面的临时新后台验证。
- 查看了移动中及落点后的截图。每轮测试只清理本轮创建的账号和房间、关闭自己的临时服务；用户原服务与数据库未停止，没有 seed/reset 或修改 .env。

早期失败如实记录：首次测试把鼠标落点误当整数世界坐标，缩放后实际会有亚像素差，已改为以服务端真实确认坐标验收；同一浏览器上下文的多个标签页受到后台动画帧节流，改用独立窗口上下文验证前台观察者，并增加产品归位兜底。初期测试退出时，已关闭 HTTP 连接仍有快照查询在执行，过早断开测试数据库连接产生 Engine empty 日志；测试服务改为等待查询完成再清理，复测无该日志。

## 启用与未验证项

本轮没有停止用户正在运行的旧后台。关闭“启动跑团”窗口，再双击启动跑团.bat，并让各成员刷新网页，才会加载新后台广播和新网页。原数据库、上传图片、端口及外网配置保留。

未进行实际异地公网联机、目标 5600G 服务器帧率/CPU/内存压测、多日运行或全部浏览器套件。没有精确重放鼠标绕行路径；当前演出明确为起终点直线。广播故障采用代码兜底，本轮没有人为注入网络层广播失败；人物卡数值及战斗裁决逻辑未改动。
