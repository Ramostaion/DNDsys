# 地图棋子复制、删除权限修复

日期：2026-10-11。

## 实施

- 玩家右键菜单保留查看人物卡与查看角色标签，复制和删除按钮仅 GM 可见。
- 新增仅 GM 可调用的 `token.copy` 操作，以源棋子为依据复制位置与关联人物卡，保持原可见范围，避免隐藏棋子复制后公开。
- `token.delete` 后台强制检查 GM 身份，玩家本人和获得人物卡编辑授权的玩家都不能删除棋子。
- 玩家通过旧 `token.create` 接口或重复拖放，同一地图、同一角色再次生成棋子时返回 403，避免绕过复制限制。
- 玩家首次放置有控制权限的角色，以及按既有控制权限移动棋子继续可用。
- 保留现有棋子和人物卡，没有数据迁移、批量清理或新增依赖。

## 验证

- 类型检查、代码检查、共享模块／后台／网页构建通过。
- 两项相关真实浏览器回归均通过：新增棋子管理权限测试和既有角色标签地图测试。
- 新增真实浏览器与 API 回归覆盖玩家自己／他人棋子菜单、人物卡授权后仍禁止复制删除、直接调用接口与旧创建接口绕过被拒绝、首次放置与本人拖动、GM 菜单复制删除、多玩家同步、删除棋子保留人物卡以及隐藏棋子复制后继续隐藏。
- 既有角色标签地图测试继续通过，验证 Token 拖动、地图切换与标签详情交互。
- 测试只使用临时账号、房间和棋子，结束后清理；用户原有房间数据保留。
- 尚未验证 Firefox、Safari 和跨设备联机；本次未执行完整浏览器测试套件。
