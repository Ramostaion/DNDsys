# 行动顺序 HUD 视觉优化

日期：2026-10-18。

## 设计与实现

保留顶部横向先手顺序条，方向为深蓝黑、淡金色与暖白文本的现代奇幻策略游戏界面。

| 部分 | 当前方案 |
| --- | --- |
| 标题 | 左上14px「行动顺序」，下方12px「地图名 · 第N轮」；长地图名弹性收缩，轮次保持完整 |
| 设置 | 右上统一30px细边按钮，使用Lucide线形设置图标，提供键盘焦点和完整名称 |
| 人物节点 | 序号徽章、圆形头像、名称纵向工整对齐；状态图标收在名称下方，动作指示符在底部 |
| 当前行动 | 头像放大1.055倍，薄金边；淡金色光环4.2秒柔和呼吸，名称暖金高亮，底部细线与小菱形指示 |
| 已行动 | 透明度0.56、轻微降饱和，序号附勾选标记，与当前和待行动者明确区分 |
| 待行动 | 保持正常亮度；下轮参与者进一步弱化，原资格与选择规则不变 |
| 长名称 | 最多两行，保留完整名称悬停提示；桌面14px、窄屏13px，不退回单行粗截断 |
| 面板 | 半透明深蓝黑渐变、微弱细纹理、1px淡金描边、顶部细光和轻微内阴影；没有图片纹理或粒子 |
| 本轮进度 | 底部显示当前账号可见人物的已行动数及细进度条，不统计无权查看的人物 |

古典金色基础为 `#D4AF57`，大部分边线和光晕使用低透明度；正文使用暖白，不使用高饱和厚金框。纹理由CSS细渐变生成，零额外图片或字体下载。

光环只动画opacity/transform，阴影保持静态。原260ms权威队列重排、240ms结束淡出继续保留；移除逐头像依次入场的动画，避免已行动人物在刚进入时短暂恢复高亮。减少动态效果时光环和过渡停止，当前人物仍有静态描边、名称和指示符。

## 空间与交互

桌面最大宽680px，角色多时内部横向滚动，当前行动者仍自动滚入可见范围。701–760px且右侧队伍仍显示时，HUD靠左并收窄，避免挡住队伍；700px及以下沿用页面隐藏队伍后的可用宽度。480px继续横向滚动，保留名称两行及状态详情。

点击头像、打开GM设置、状态悬停/点击、键盘操作、暂停/上限提示、当前人物自动可见和权限过滤继续使用原逻辑。进度条只按当前权限快照的 `firstRound` / `lastActedRound` 计算显示，不推进回合。

## 范围

仅修改 `apps/web/src/ui/turns/TurnHUD.tsx`、`turns.css`，扩展原 `apps/api/e2e/turn-system.spec.ts` 的视觉验收数据与截图。没有修改先手得分、轮末重建、状态持续时间、Socket/API或数据库。

原5242后台保持运行，本轮不代为重启。当前正式静态服务按请求读取index.html，已更新正式构建，刷新网页即可加载新样式。
