# 日常跑团界面与手动操作修复

日期：2026-10-11。

## 实施状态

| 用户问题 | 实际修改 |
| --- | --- |
| 1. 杂物出现防御，JSON 和修正不适合日常使用 | 物品卡去掉固定防御、装备数值修正及 JSON 输入；可添加任意项目名称，选择文字或数值，另有描述和备注。新建杂物不附加防御数据。 |
| 2. 物品库只有列式展示 | 改为与背包风格一致的缩略图格子，名称与种类可见。 |
| 3. 物品库直接拖入背包 | 支持物品格拖入有权限的角色背包；空格指定位置，已占用格寻找其他空格。保留下拉加入方式。 |
| 4. 模板头像像 OCR，数值修正不必要 | 独立的大图标预览与“选择图片”按钮，明确是能力图标；删除数值修正编辑区。 |
| 5. 添加标签替换已有列表 | “添加标签”直接进入新建定义，保存后设置角色备注并分配；已有列表始终保留；复用定义独立使用“从标签库选择”。 |
| 6. 人物卡功能顺序 | 改为能力与状态 → 管理标签 → 编辑人物卡 → 背包 → 装备；继续按 GM 身份及背包可见权限显示。 |
| 7. 派生公式不易用 | 移除人物卡与字段页的公式编辑入口和公式插入按钮，新字段以手动数值、文字、是/否和选项为主。 |
| 8. 找不到人物血条 | 字段页新增“设置血条”，可一键添加生命字段或关联已有两个数值字段。每个角色在人物卡独立修改当前生命和上限。 |
| 9. 先攻应由 GM 人工控制 | 去掉先攻输入与排序机制，GM 指定任意参与者行动、上移/下移顺序及手动设置轮次；保留“下一位”快捷操作。 |
| 10. 时间线缺少行为玩家 | 每条记录显示操作账号、关联行动角色、目标与时间，退出房间的玩家姓名也可通过记录关系读取。 |

新物品的自定义项目和新能力的说明用于资料记录，实际数值变化由人工调整人物卡。新增窗口尺寸更适合物品、背包及能力编辑；避免关闭中间窗口后，新窗口完全覆盖已有标题位置。

## 血条操作

1. GM 打开人物卡的“编辑人物卡”，或侧边栏“字段”。
2. 点击“设置血条”，首次可以“一键添加生命血条（默认 20 / 20）”。
3. 打开角色人物卡的“生命”分组，设定该角色当前生命与生命上限。
4. 扣血、治疗使用手动设定或增减按钮；保存后有权限的其他客户端同步更新。

旧版人物卡已有生命血条，上限沿用原规则；新入口用于自定义人物卡。
